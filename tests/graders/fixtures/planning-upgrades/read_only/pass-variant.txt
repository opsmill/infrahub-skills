# Upgrade plan: 1.10.8 to 1.11.0

This plan does not run the upgrade. Roll up to the latest 1.10 patch first,
then take the single supported minor hop. Upgrade `infrahub` only after the
`tasks.py` fix below has landed.

## 1.10.8 -> 1.10.10 (patch roll-up)

| Change | Release | Kind | Severity | When | Affected | Evidence | Action | Source |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| Neo4j must move to 2026.05.0 | 1.11.0 | preparation | warning | during | unknown | Separately managed database; not visible from the repo | Run infrahubctl info to read the deployment, then upgrade Neo4j alongside Infrahub | https://github.com/opsmill/infrahub/releases/tag/infrahub-v1.11.0 |

```bash
kubectl exec deploy/infrahub-server -- infrahub db showmigrations
kubectl exec deploy/infrahub-server -- infrahub upgrade --check
```
