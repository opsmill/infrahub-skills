## Plan

Do you want to include traces? Only a share of requests has a trace, so a super admin raises the ratio first:

```bash
export INFRAHUB_ADDRESS="https://infrahub.example.com"
curl -X PUT "$INFRAHUB_ADDRESS/api/troubleshooting/trace-sample-ratio" -d '{"ratio": 1.0, "duration_seconds": 1800}'
infrahub-collect create --include-traces --traces-min-duration 1s --traces-since 30m
```

Never send `DELETE /api/troubleshooting/trace-sample-ratio` after the bundle is created.
