# Model Designer Rule Sections

| Category | Prefix | Description |
| -------- | ------ | ----------- |
| Interview | `interview-` | How each question is asked, how design directions are offered, and how the user's files are used |
| Scope | `scope-` | When a request is split into features, and what the sketch then covers |
| Brief | `brief-` | The value drivers the design serves and the features that serve them, what every sketch row and every decision in the brief must carry, the maps drawn from them, the reference design they follow, the mechanisms behind each artifact, the features each open item affects, and the next steps |
