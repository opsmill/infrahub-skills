# Infrahub Concept Tutor - Rule Sections

1. **Protocol (protocol-)** -- CRITICAL. Probe before
   teaching, the structured lesson shape, progress
   recording.

2. **Safety (safety-)** -- CRITICAL. Instance writes:
   opt-in, learning-* branch only, cleanup, never the
   default branch.

3. **Exercise (exercise-)** -- HIGH. Verified reference
   solutions, learner-authored artifacts, the hint
   ladder.

4. **Grounding (grounding-)** -- HIGH. Teach through the
   learner's own artifacts; cite docs.infrahub.app for
   behavior claims; off-map concepts go through the
   shared docs fallback; comparisons cite official
   sources or say unsure.

5. **Handoff (handoff-)** -- MEDIUM. Graduation pointers
   to the sibling skills.
