The managing-generators, managing-transforms, managing-checks, managing-objects and managing-menus skills now also trigger when you edit a file in the directory they cover, such as `generators/`, `transforms/`, `templates/`, `queries/`, `checks/`, `objects/`, `data/` or `menus/`, even when your request does not name the task. The removed `SessionStart` hook used to give Claude these path rules. The installation page now has a `CLAUDE.md` section you can add to your Infrahub repository to make Claude read the matching skill before it edits one of these files.
