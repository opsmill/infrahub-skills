Removed the `SessionStart` hook that detected Infrahub projects. The Claude plugin directory holds or refuses a command hook whose script uses variables, wildcards, command substitution or a here-document, and the detection script needed all of them. Claude Code still picks each skill from its description, so you do not need to name a skill to use it. The instructions the hook gave to detect the project's Python environment before running `infrahubctl`, and to dry-run a changed `.gql` file, are now in the schemas, objects, menus, checks, generators and transforms skills.
