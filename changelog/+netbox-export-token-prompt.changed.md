The NetBox export script no longer reads the `NETBOX_TOKEN` environment variable. Run it in your own terminal, or with the `!` prefix in Claude Code, and it asks for the API token at the keyboard, so the token stays out of your shell history and out of the conversation. The query for the module ports generator is now a GraphQL block in `generators-module-ports.md` instead of a separate `.gql` file: save it as `queries/materialize_module_ports.gql` in your repository. The Claude plugin directory refuses a plugin script that reads a credential from the environment, and accepts only Markdown, text, JSON, YAML and images from a plugin.
